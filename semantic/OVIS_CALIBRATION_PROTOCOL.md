# 第七轮：冻结模型的背景分数校准

固定第六轮两种标签方案的线性2000步模型，种子0/1/2。只对背景logit添加一个常数，不改变前景类间排序、模型参数、训练标签、特征或查询。

候选偏移预先固定为 −8 到 +8、步长0.25，含0。每种标签方案只选一个跨三个种子共享的偏移，以三个种子的平均验证宏F1为目标；同分优先最小绝对值，再选负值。测试不参与偏移选择。只有偏移确定后才报告该模型的测试变化。

评价校准前后总体宏F1、前景宏F1、背景F1、前景正确率、前景判背景率、逐类和逐帧结果，并保存完整验证曲线。真值仅来自原验证/测试评价查询，训练没有开放后续帧真值。校准超参数本身使用验证真值，不能宣称完全无监督校准。

零偏移必须逐种子复现第六轮结果；模型文件哈希校准前后相同；新增单元测试覆盖零偏移等价、并列分数规则、背景选择单调性、验证目标选择及logit不变。若单一校准恢复前景并保留背景，则支持决策竞争的解释；否则不能证明校准无效，仍受共享常数及验证分布限制。
