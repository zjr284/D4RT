# 第十六轮：冻结DINOv2语义分支的D4RT接口验证

本轮只验证接口正确性和计算成本，不训练、不校准，不是新的泛化确认。复用第十五轮按平均验证宏F1选定的coverage80_sam_background、种子0/1/2语义头及背景偏移−1.75，冻结D4RT/DINOv2权重及128→224预处理。

接口接受RGB `[B,T,3,128,128]`（0至1）与原查询`u/v/t_src/t_tgt/t_cam [B,Q]`。建议保留RGB float32给语义分支；D4RT在CUDA BF16 autocast下直接接收同一输入，不修改几何查询或代码。返回全部原几何字段、原始及校准语义logits `[B,Q,26]`、类别 `[B,Q]`。语义特征只读取源RGB帧、u/v及t_src，像素中心映射后双线性采样，量化至原float16缓存精度，再用float32分类头。背景偏移只应用类别0，不改变权重。接口为冻结推理，不支持训练模式。

DINOv2每视频的全部帧共同提取patch tokens，与确认缓存的图像批量方式一致。输入RGB不能从BF16还原已损失的颜色精度；同样查询的原几何保持以传入RGB相同、同autocast的原D4RT输出为参照。不会偷偷把几何输入转换后宣称等价。

先固定以下测试，不按预测结果挑查询或调整阈值：

1. 单元检查使用确定性替身模型，覆盖B=2、多查询与单查询、源帧与坐标影响、边界、非法坐标/时间/形状/数据范围、背景偏移、checkpoint重载、参数冻结和输入不变。所有六几何字段必须保留。
2. 真实视频固定第十五轮已观察确认清单前3段（153/52/395），每段从2048个既有查询按等间隔取64个，共192个缓存查询；另每段加8个包含角点、中心与非整数坐标的边界查询。选点只依索引/坐标规则，类别与分数不参与。B=1真实检验，B=2仅单元覆盖，不能声称所有批量已验证。
3. 与原模型同输入前向比较六项几何输出，目标为逐值相同，失败时保存最大/平均差并排查；不改权重消除差异。改`t_tgt=(t_tgt+1)%8`、`t_cam=(t_cam+3)%8`，语义logits/类别须逐值相同；原几何对改变后的同查询再次保持。
4. 三种子均检查float32 RGB的在线语义特征/logits与原确认缓存的差异与类别改变数；允许记录坐标浮点往返及量化/推理批量差异，不因确认F1更好而改实现。另在第一段固定BF16 RGB输入诊断颜色量化影响，不把它当新的模型成绩。原/校准logits和类别应自洽。
5. 每段冷调用记录原D4RT前向和完整接口耗时、CUDA峰值显存；不作重复择优计时，不声称标准基准或生产吞吐。实际权重重载后语义logits须一致。报告所有失败与范围限制。

保存模型/三头/缓存/选点指纹，运行前后哈希相同；本轮不改变第十五轮模型选择、分数或视频使用记录，已处理视频仍420段。产物`semantic_artifacts/dino_interface_probe/`；入口`.venv/bin/python -m semantic.dino_interface_probe`。核验后代码、报告及文本快照独立提交推送，不提交数据/模型/特征。
