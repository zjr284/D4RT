# 第十四轮：语义特征与独立视频覆盖的2×2对照

问题：每类至少3段训练视频的源帧查询覆盖，在DINOv2特征下是否比随机80段更有效？固定第十一轮random80/coverage80及同一20段验证，比较D4RT/DINOv2×random80/coverage80，全部仅源帧GT监督，无新增SAM标签。

复用已完成九份模型：第十一轮两训练集D4RT GT三种子头、既定偏移−1.25/−0.75；第十三轮random80 DINOv2三种子头、偏移−1.5。仅训练coverage80 DINOv2三个线性头，固定2000步，每步前景/背景各128，AdamW lr=0.001/weight_decay=0.01，每50步按原始验证宏F1选预算内最佳权重，同分更早。按三种子平均验证宏F1选共享偏移，网格−8至+8、步长0.25，同分绝对值小再负值。不得重新训练随机DINOv2基线或重选旧偏移。

特征提取严格复用第十三轮DINOv2骨干权重、源码commit、128→224图像预处理及像素中心双线性采样；只补训练并集中多出的20段源帧特征，复用既有80段及全部验证特征。D4RT源帧和DINOv2查询标签、坐标、源/目标/相机时间逐值相同。两训练集均80段，重叠60段，覆盖组实际每类≥3独立查询视频。

在模型训练/新确认评价前，排除已经处理340段，从剩余267段以seed=20261016随机固定40段确认；不按Bear、类别覆盖或旧确认失败挑视频。候选源帧类别元数据此前被检查，称模型未评价集合，不称完全未观察标注。保存清单、协议、输入指纹；新确认模型输出仅在全部权重与偏移冻结后产生。验证集已有选择影响，预训练OVIS图像重叠仍未知。

报告三种子原始/校准指标、全部出现类、相同视频配对差、两个特征内的覆盖差、两个训练集内的特征差，以及交互差`(DINO覆盖−DINO随机)−(D4RT覆盖−D4RT随机)`。固定seed=20261016的视频bootstrap为2000次，估计视频等权出现类宏F1差，不是汇总查询宏F1区间。保存全部类别和负结果，若确认不出现Bear也不换视频；缺失支持明确记为空。

对随机组有源帧训练支持且确认出现的共同前景类，保留全确认假阳性后作宏F1描述；另报告源/后续帧错误分解。覆盖筛选改变具体视频、类别比例及外观，效果只归于整体等视频数选择干预，不唯一归因于数量或多样性。不得据新确认选下一轮参数。

独立核验：从GT重建40段查询，检查每训练组140段、训练并集共160段的查询元数据、覆盖及全部输入内容哈希；重算12模型的24份验证/确认输出；验证三个新头的采样预算/最佳步骤/校准，旧九模型与偏移不变，旧验证成绩复现。
