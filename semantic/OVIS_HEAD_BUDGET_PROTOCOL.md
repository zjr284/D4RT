# 第五轮：分类头与训练预算诊断

## 固定设计

复用第四轮完整真值训练缓存，共60段训练视频、20段验证视频和20段测试视频。只训练语义分类头，OpenD4RT 冻结；本轮仍是开放训练后续帧真值的 oracle 诊断，不是首帧弱监督结果。

| 分类头 | 结构 | 训练预算 |
|---|---|---|
| linear | Linear(1280,26) | 500、2000步 |
| mlp | Linear(1280,256) → GELU → Linear(256,26) | 500、2000步 |

不增加归一化或 dropout。两类头每种子只有一条2000步轨迹；500步结果选取前500步内最佳验证模型，2000步结果选取前2000步内最佳验证模型，不重启训练。每类头三个种子0/1/2，共六条训练轨迹、12个预算结果。

每步前景/背景各128查询、组内查询均匀抽样，AdamW lr=0.001、weight_decay=0.01。每50步按验证宏F1选择 checkpoint。头和预算的组别选择仅看三种子平均验证宏F1；测试只用于最终诊断，不调学习率、隐藏层宽度或训练预算。

记录训练、验证、测试缓存内容哈希与 manifest 指纹。数据、真值标签、视频划分、查询和冻结特征保持不变。输出目录 `semantic_artifacts/head_budget_probe/`，不覆盖前轮产物。

## 观测和解释

报告训练拟合、相同前景类别训练/测试宏召回率、前景/总体宏F1、前景被判成背景率、排除背景竞争的前景正确率、逐类指标、选中步数和实际采样计数。

若更长训练恢复测试识别，则预算/优化是可干预因素；若非线性头在相同预算提升，则分类头形式或容量值得进一步检验。MLP同时改变容量和非线性，不能将效果唯一归因于非线性。若训练拟合更高而测试仍低，则支持泛化限制，但不能证明 OpenD4RT 不含语义信息，也不能排除视频覆盖、特征尺度与其他优化配置的影响。三个种子来自同一划分。

## 运行与核验

```bash
.venv/bin/python tests/test_head_budget_probe.py
.venv/bin/python -m semantic.head_budget_probe > semantic_artifacts/head_budget_probe.log 2>&1
```

自动核验线性500步结果与第四轮逐种子一致、采样预算无超额、每个预算选中步数不越界。测试覆盖 MLP 梯度、真实非线性及权重重载一致性。
