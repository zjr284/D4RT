# 第十三轮：独立冻结语义特征对照

问题：使用相同训练视频、源帧GT查询及线性头预算，DINOv2的局部图像特征是否比现有D4RT查询特征更适合跨视频类别识别？这是完整特征方案对照，不能唯一归因于某个网络层或预训练目标。

训练沿用第十一轮由验证选择的random80源帧GT方案，验证沿用20段；确认集从排除已处理300段后的307段，以seed=20261015随机固定40段，先保存视频清单，再提取/评价。307段的源帧类别元数据已被覆盖筛选检查，必须披露；本轮确认是模型未评价集合，而非完全未观察过的标注。选视频不使用类别覆盖目标或旧确认模型得分。

冻结D4RT基线：复用原三个种子的2000步预算最佳线性头和验证偏移−1.25，不重复训练。DINOv2方案采用官方ViT-S/14公开骨干，保存源码commit、权重SHA-256和来源。全图先与D4RT一样缩放到128×128，再固定bicubic缩放至224×224并按ImageNet均值/标准差处理；不使用类别、GT掩码、边界框、对象裁剪或文本提示构造特征。

每帧输出16×16×384的归一化patch tokens，在128图像查询像素中心`(x+0.5,y+0.5)`对应位置作双线性采样，边界复制，align_corners=False；只取源时间对应RGB帧。DINOv2不使用目标/相机时间。训练仅提取t_src=0，验证/确认评价8帧固定GT查询。共享所有查询的标签、坐标、源/目标/相机时间与video_id。D4RT使用视频上下文和1280维查询特征，DINOv2使用单帧384维特征，因此头参数数不同，改善只归于该完整方案。

DINOv2线性头固定2000步、种子0/1/2，每步前景/背景各128，AdamW lr=0.001、weight_decay=0.01，均匀组内查询采样。每50步按验证原始宏F1选择预算内最佳权重，同分取更早。随后按三种子平均验证宏F1选共享背景偏移，网格−8至+8、步长0.25，同分按绝对值更小再负值。确认输出只在模型和偏移保存后产生；本轮不搜索骨干、分辨率、特征组合、学习率或额外归一化。

保存原始/校准的验证、确认指标，全部出现类及共同训练支持类，源/后续帧错误分解、逐视频指标和三个种子配对差。视频级bootstrap固定seed=20261015、2000次，对视频平均出现类宏F1差作95%百分位区间；不能当作汇总类别宏F1区间。保留缺失训练类别与零分。本轮确认得分不用于选择方法或参数。

记录预训练数据可能与OVIS图像重叠但无法核查这一限制。验证集在此前选择中已使用，并非全新验证；固定方案没有新增验证参数搜索。数据、模型权重、第三方源码及特征不提交，只提交自有代码、协议、报告和文本结果。

入口：`.venv/bin/python -m semantic.semantic_feature_control`；独立目录`semantic_artifacts/semantic_feature_control/`。依赖及权重失败时保存固定协议和进展，排查后续跑，禁止改确认视频或偷偷换模型。

官方依据：[DINOv2模型卡](https://github.com/facebookresearch/dinov2/blob/main/MODEL_CARD.md)、[骨干实现](https://github.com/facebookresearch/dinov2/blob/main/dinov2/hub/backbones.py)。只使用公开骨干，无预训练分类头。
