# 第八轮：相同预算的纯首帧GT基线

固定原60/20/20视频划分、线性头、500/2000步嵌套预算、AdamW lr=0.001/weight_decay=0.01、每步128前景＋128背景、种子0/1/2。训练只从首轮缓存取 t_src=0 的源帧真值查询，保留原坐标和特征，不使用后续帧伪标签或真值，也不重新抽查询或提取特征。

每50步按验证宏F1选checkpoint。在2000步选中模型上，使用与第七轮相同的−8到+8、步长0.25的背景偏移候选，通过三种子平均验证宏F1选择共享偏移，不用测试分数选择。

比较纯首帧GT、首帧＋SAM正类、首帧＋SAM正类/背景三种方案，在同一线性2000步和同一校准规则下的原始与校准测试指标。SAM两组复用第六七轮结果与模型。保存相同种子的配对差值，按校准后平均验证宏F1选择标签方案。训练步数相同但可用标签数量和时间覆盖不同，这正是监督方案的整体干预。

核验所有GT训练查询t_src=0、500步逐种子复现首轮GT控制、2000步零偏移复现原结果、没有视频泄漏。训练指标只包含源帧，其他帧训练指标记为null，不制造空集合统计。

此实验是当前固定划分下的弱监督收益复核，不是OVIS官方AP；已经反复观察过该测试集，取得改善后需要在新划分/未使用视频上确认，不据此宣称可发表的稳定提升。
