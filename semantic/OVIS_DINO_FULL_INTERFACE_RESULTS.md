# 第十七轮：完整查询的双精度语义/几何接口

显式双RGB输入解决了上一轮发现的图像提前量化问题：几何继续接收原BF16图像，语义接收对应float32原图。在已观察40视频的全部查询上，在线语义输出完全复现旧缓存，同时保持同输入原D4RT的六项几何输出；真实双视频批量也通过。这是接口正确性与资源检查，没有训练、新增性能提升或新的泛化确认。

固定协议见 [OVIS_DINO_FULL_INTERFACE_PROTOCOL.md](OVIS_DINO_FULL_INTERFACE_PROTOCOL.md)。模型仍是第十五轮验证选定的coverage80_sam_background、种子0/1/2，背景偏移−1.75，两个骨干及三头均冻结。

## 完整验证结果

第十五轮40段已有确认视频，每段2048查询，三个种子，形成120个B=1案例。另固定清单前两段153/52，真实B=2，每视频2048查询，三个种子形成3个批量案例。

- 原查询及`t_tgt+1/t_cam+3`模8后，每案例各六个几何输出，与**相同批量、相同BF16输入**的原D4RT逐值相同：1476组数组比较，最大/平均差均零。
- 123案例的语义分数及类别不随目标/相机时间变化，全部逐值相同。源时间、坐标仍参与语义；输入不变，全部模型参数冻结。
- B=1共81920个原查询的在线DINOv2特征逐值复现缓存，三个种子的原始分数也逐值复现保存结果，245760次种子×查询类别比较无变化。
- B=2共12288次种子×查询类别比较无变化；三种子的语义原始分数与对应B=1及旧缓存逐值相同。这里没有要求或声称几何跨B=1/B=2数值相同。
- 单元检查覆盖合法双输入、原单输入兼容、错误图像/形状/精度/设备拒绝及既有查询边界、时间一致性、冻结、重载检查。本轮无失败或OOM。

独立验证脚本从保存的全部在线原始分数重算类别，再用混淆矩阵公式重算总体及每视频指标；旧预测/真值顺序按video_id对齐。三个种子的宏F1和前景宏F1与原记录差均为零：

## 双RGB输入用法

```python
rgb = load_video(clip)[None].cuda()  # float32，0至1，128×128
outputs = adapter({
    "video": rgb.to(torch.bfloat16),  # 原几何输入精度
    "semantic_video": rgb,           # 对应原图保留颜色精度
    "query": query,
})
```

`semantic_video`必须为float32，与video形状、设备相同，且`semantic_video.to(video.dtype)`逐值等于video；否则明确拒绝。这个检查保证量化对应，不能从一个已量化视频中验证或恢复其唯一的原始颜色。上游仍须保留原图。接口不读取掩码、类别真值或目标帧提示。

没有semantic_video字段时行为与第十六轮一致；只传入BF16视频仍会有上一轮记录的语义颜色精度差异。增加双输入没有修改几何代码、权重或背景偏移。
