# 第十轮：冻结确认输出的错误与覆盖审计

本轮是对第九轮40段确认视频的描述性诊断，不是新确认实验。使用已经冻结的九组logit及三个既定背景偏移，禁止更新权重、阈值或根据诊断重新选择模型。

对每个方案和种子分解：真前景预测正确、真前景判背景、真前景判其他前景类；真背景预测正确、真背景判前景。前景三类计数之和必须等于前景支持数，背景两类之和必须等于背景支持数。保存逐视频分解和完整混淆矩阵，必须逐值复现第九轮。

审计原训练缓存各类的查询数、不同(video,x,y,t)数、独立训练视频数及时间分布；GT基线只取t_src=0。固定覆盖分组为1个、2–3个、至少4个训练视频，报告所有在新确认集中出现的22个前景类。类频/视频覆盖与成绩的联系仅是观察性分析，不作因果断言；同一视频不同坐标不是独立视频。

记录十个计数最高的前景类间错误对，以及所有22类SAM前景/背景相对GT的F1差，不挑选有利类别。训练缓存和logit内容哈希在分析前保存；检查添加背景没有改变SAM正类覆盖。

运行：`.venv/bin/python -m semantic.frozen_error_audit`。产物：`semantic_artifacts/frozen_error_audit/`。无论诊断是否支持原假设，均保存结果并逐轮提交Git/GitHub。
