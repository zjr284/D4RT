# 第九轮：未使用视频的冻结模型确认

固定此前三种监督方案的线性2000步模型与背景偏移：纯首帧GT −1.25、SAM前景 +3.5、SAM前景/背景 −2.0；每方案三个种子。禁止训练、重新校准或按结果选择模型。

从OVIS 607段中排除原manifest全部100段，以及本地已有教师/特征缓存中的pilot视频。以seed=20261013随机打乱合格未使用视频，选前40段；不按类别或模型成绩替换视频。合格定义沿用旧协议：至少8帧、有可作源帧的实例标注、对应8帧文件齐全。选择manifest与所有模型哈希在推理前保存。

每段8帧、128×128，用既有采样规则每帧前景/背景各128查询（池为空则不造样本），查询seed=42+video_id。GT只用于本轮评价。冻结OpenD4RT提取一次decoded特征，九个头共享完全相同查询和特征。前景类别仅从训练已知的25类中预测；不存在新调参。

报告全局查询宏F1、前景宏F1、背景F1、逐类/逐帧结果和同种子差值。另对每视频出现类别计算宏F1，跨模型种子平均配对视频差，以2000次视频重采样给出其平均差的95%百分位区间。此区间是“平均逐视频宏F1差”，不是全局查询宏F1差的置信区间；三个模型种子也不能替代40个视频的独立性。

这是固定模型在OVIS同一训练数据来源的未使用视频确认，不是独立数据集或官方OVIS AP。新视频可能出现与原测试不同的类别组成，不能直接比较新旧全局宏F1高低；应看新视频内部相同查询上的方案差异。无论正负结果均保存、提交Git并推送GitHub。

运行：`.venv/bin/python -m semantic.fresh_video_confirmation`；产物：`semantic_artifacts/fresh_video_confirmation/`。
