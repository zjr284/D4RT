# 第十二轮：冻结模型的源帧与跨视频错误审计

本轮是对第十一轮已观察结果的描述性诊断，不是新确认实验。只加载四方案×种子0/1/2的2000步预算最佳权重，沿用原验证选定偏移；不训练、不重校准、不换视频或选择方法。

预先固定以下分析，再计算新的诊断指标：

1. 每方案在自身80段训练视频的**源帧GT查询**上评价；SAM与GT共同使用相同源帧真值，不把SAM后续伪标签正确率当真值训练拟合率。另在两训练集重叠60段的相同源帧查询上作配对评价。
2. 验证/确认复用既有输出，分别报告全部8帧、源帧t_src=0、后7帧t_src>0。固定偏移对全部子集一致。源帧对照用于检查跨视频差距是否在没有源时间变化时仍出现。
3. 所有子集保留26类预测空间。统计前景正确、前景判背景、前景判其他前景的闭合分解，逐类GT查询数、独立视频支持、F1/召回，以及前10个前景混淆对。汇总指标先逐种子计算再平均。
4. 对四方案训练源帧、验证源帧、确认源帧**均出现**的共同前景类，等权计算F1与召回。逐类F1的假阳性来自完整子集，不删除其他真类别的查询。共同类按标签支持确定，不按分数挑选。
5. 对确认全部帧出现类作固定描述分组：训练源帧无支持；有支持且三种子平均训练召回<0.5；训练召回≥0.5且确认召回<0.1；其余。阈值不是模型决策规则，不用于下一轮训练或调参；“训练拟合但确认失败”不等同于证明编码器或外观是原因。
6. 保存全部25类信息及负结果、逐种子/逐视频源帧指标，记录输入权重、输出、特征内容哈希；核验第十一轮的验证/确认指标逐值复现，输入分析前后未变，SAM/GT源帧评价元数据相同。

训练源帧查询也用于训练，分数是样本内拟合诊断而非泛化成绩。验证集曾用于选模型/偏移，其成绩有选择影响。不同视频和查询分布、类支持与空间位置仍可能影响差距；时间子集不是干预的因果证据。现在没有新的未观察确认结果。冻结分析不能据当前确认分数选择后续模型。
