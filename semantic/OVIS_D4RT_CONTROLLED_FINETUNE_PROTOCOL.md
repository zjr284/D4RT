# 第99轮：本体LoRA与SAM辅助监督的固定预算探索

先有第98独立核验和单独推送，再执行本轮。只用原OVIS60训练/20验证缓存，三个种子0/1/2；全607已用于研究，故本轮仅探索，不是新确认。旧test20及外部40不评分，新外部数据未启动，默认部署不变。

四方案均重跑相同末两decoder层；原权重/编码器/前六层/六几何头/out_norm冻结。1280→26分类头、rank8/alpha16 FF LoRA，seed内全方案同初始化，eval模式关闭dropout但保留梯度。A仅更新头；B/C/D更新头与同样的LoRA。AdamW lr=1e-4、weight_decay=.01，固定500步最终权重，不早停、不校准、不搜损失系数。全部12适配器保存并冻结后才统一读验证成绩。

训练GT视频从全部60段均匀抽，首帧32FG+32BG为共同GT；另外从同段首帧FG抽32作额外GT参照。SAM辅助视频独立从训练60中有后帧正伪标签的段抽，取后帧32FG；每个视频是否可用于辅助和支持数在协议内完整记录，不能因效果丢GT训练段。随机seed20261099+seed生成500步共享日程。所有方案每步都前向同样的GT64+额外GT32及SAM32；没有辅助标签的点不当BG，也不把SAM/GT输入特征。各种子GT曝光32000、额外GT/SAM候选各16000；只有有系数的项产生监督。

损失固定：A=GT_CE；B=GT_CE+0.1*geometry；C=B+0.25*SAM_CE；D=B+0.25*extra_GT_FG_CE。几何为同日程、同96/32查询块BF16冻结末两层的13维SmoothL1。参照按种子预先保存，所有臂共用；六输出各自误差也保存。C−B代表加入SAM后帧伪标签的整套监督收益，混入额外FG量，不能唯一归因SAM知识；D控制等量首帧FG重复监督，C−D仍有后帧外观等差异，不唯一归因teacher质量。

主对照C−B；必要微调对照B−A；次要C−D。只报告既有验证raw argmax的宏F1、前景宏F1、逐类支持/混淆/每视频F1和三seed差、简单视频等权均差；不作新泛化显著性检验。使用相同查询块64、原alternate_prelast记录目标/相机变动的一致率。几何对相同缓存/块大小/精度的冻结基座记录六项mean/max绝对漂移，不能称几何真值准确率或保证保持。

源探索进入未来语义外测的资格：C−B与C−D三种子pooled宏F1均正，且两个对照的视频等权平均差均正。此规则只决定是否值得另立新数据协议，不是新确认或部署许可。若不满足，保留负结果，不立刻消耗新外部样本。无真实几何基准就不能宣称原三维性能保持。
