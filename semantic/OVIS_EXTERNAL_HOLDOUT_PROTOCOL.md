# 第三十六轮：外部冻结复核的数据入口与类别映射准备

第35提交推送后立即开始。OVIS607段均已用于研究；本轮不重新训练/评价它们。目标是检查官方外部数据公开入口、实际注释下载、类别映射和资源，为新跨数据集复核准备可执行边界，不冒充已经有外部性能结果。

冻结第33相同GT256/GT32/lambda0/nativeSAM四方案三头和既有偏移（−1.5/−1.25/−1.5/−1.75），GT32是之前按OVIS验证选中的候选，不能按第33最高quarter改池。当前部署GT256不变。新数据不得训练/重校准这些头，也不得用外部得分改阈值或类别映射。

优先检查[YouTube-VIS官方入口](https://youtube-vos.org/dataset/vis/)及[官方使用说明](https://youtube-vos.org/dataset/term/)，官方首页已说明验证/测试GT公开。若官网链接的CodaLab数据路径不可用，检查[LV-VIS作者仓库](https://github.com/haochenheheda/LVVIS)公开验证注释作为备用。该作者说明验证VIS格式与2019一致，另有image oracle注释，训练注释并非穷尽且工具使用SAM/STCN；须披露这些条件，不能宣称完全独立人工标注或所有像素GT均完备。仅非商业研究，不重分发数据/第三方源码，不联系作者、不注册账户或使用付费计算。

本轮只公开HTTPS GET（证书验证保持开启），页面单文件上限4MiB、注释单文件上限192MiB、总体上限256MiB；不下载完整视频档案。保存响应状态/输入快照哈希、下载是否真JSON及是否具有VIS videos或COCO images结构、类别与标注计数。登录/403/失效/TLS错误按原样记录，不绕过。检查本地磁盘、GPU与已有依赖，不安装大框架。

映射预先固定为名称严格匹配：小写、下划线改空格、合并空白。不把eagle/owl并为Bird、goldfish并为Fish或sedan/truck并为Vehical；外部未知/非共享类掩码标−1而不是背景0，重叠也−1。框架实现并以真实注释类别元数据审计共同集合；类别元数据已经检查须披露，不能据模型得分删类。临时准备采用已注释共享前景查询，避免不穷尽注释下把未标物体当背景GT，仍不称全数据集AP或自然像素评测。

正式新复核须在下一协议中先固定数据版本/哈希、排除与OVIS源帧的重复检查、完整模型与偏移/查询recipe、确定性40段及备用保留集（若不足如实缩小，不造新40）。每段前8帧或第一段有共享类源标注的连续8帧，候选条件只来自标注/文件可用性，不能按预测挑选。GT仅采样/评价，不裁剪或提示RGB特征。数据不重合与骨干预训练重合仍需分别披露，若图像不可访问不能启动评分。

保存自有接口/审计代码、来源链接、参数冻结文本与资源/失败报告，经独立核验白名单提交推送后立即推进正式数据准备或必要阻塞排查。入口`.venv/bin/python -m semantic.external_holdout_readiness`，产物`semantic_artifacts/external_holdout_readiness/`。
