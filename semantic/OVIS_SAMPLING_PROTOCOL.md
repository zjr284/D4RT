# 第三轮：源时间匹配与前景类别平衡

## 固定设计

在第二轮背景补充后的同一训练缓存上做 2×2 控制实验：

| 组别 | 前景采样 | 背景源时间 |
|---|---|---|
| baseline | 查询均匀 | 背景查询均匀 |
| time | 查询均匀 | 每步逐点匹配已抽到的前景源时间 |
| class | 类别均匀，再在类内查询均匀 | 背景查询均匀 |
| time_class | 类别均匀，再在类内查询均匀 | 每步逐点匹配已抽到的前景源时间 |

`time` 不重新抽样前景，不丢弃任何前景类别；只是对每个已经抽到的前景查询，从同一源帧的背景池抽背景点。没有背景支持的源时间直接报错，不静默排除。`class` 对训练缓存中出现的前景类别等概率采样；不使用测试类别频率，不对不存在的类别制造样本。类别平衡会改变前景源时间边际分布，因此组合组用于检测交互作用，不把两者预设成互不影响。

四组均为冻结特征的同一线性语义头，种子 0/1/2，每种子 500 步，每步前景/背景各 128 查询，AdamW、学习率 0.001、权重衰减 0.01。每 50 步按验证集宏 F1 选 checkpoint；组别选择只使用三种子平均验证分数。报告所有组别的测试结果，不按测试分数调参数。

划分保持 60/20/20；训练特征、标签以及全部验证/测试查询不变，不重新调用 SAM 或提取特征。实验开始前记录全部缓存内容 SHA-256 和 manifest 指纹，输出目录 `semantic_artifacts/sampling_ablation/`。

## 观测与解释

- 保存实际抽到的源时间×类别计数，确认干预确实实现预定分布。
- 测试背景 F1、前景宏 F1、总体宏 F1、逐类召回率与 F1、前景被判背景的比例、逐帧指标及完整混淆矩阵。
- 比较相同种子的 `time−baseline`、`class−baseline`、`time_class−class`、`time_class−time` 差值。
- 若只改类别采样恢复前景，而时间匹配无效，则支持类别频率偏置的解释；若匹配源时间也有效，说明源时间监督分布是可干预因素。若两者都无效，不能据此断言表征不足，仍需检查标签覆盖、特征可分性及训练预算。
- 同一划分的三个种子是初步机制诊断，不能建立跨视频划分的稳健性或唯一因果关系；本轮结果不是官方 OVIS AP。
