# 第二十五轮：冻结原JPEG语义特征缓存的正确性和成本

第二十四轮复盘推送后立即运行，不训练/校准，不消耗新视频，不再次用最终40评分。复用native_gt三头和−1.5。新独立缓存适配器只缓存原JPEG的128几何参照与448 DINO patch tokens，不能缓存分类分数；每次query仍独立采样/量化，分类头重载后重新计算分数。

每次读取原文件字节并计算SHA256，按有序内容指纹、骨干参数版本/存储指针/设备/dtype建立键；source改变必须失效。缓存命中仍严格核对传入几何RGB。冻结骨干须eval；缓存上限两视频、LRU淘汰，提供clear。不使用GT/类别/目标相机时间作键或输入。原几何直接交原模型，旧无缓存入口保持不改。

单元检查用临时图像/替身覆盖命中、头重载不复用旧预测、内容改变失效、错配来源拒绝、骨干版本改变失效、LRU/clear、参数冻结及时间一致性。只修改临时副本，不改OVIS原帧或真实骨干权重。

真实固定第二十二轮已有确认清单前3段，每段2048查询三种子；B=2固定前两段。比较缓存/无缓存的六几何、特征/原始与校准logits/类别，目标为同输入逐值相同，记录全部差异；改变tgt+1/cam+3模8、源时间以及256查询子集时与相同输入无缓存参照比较。不得用GT成绩修实现，不报告新泛化提升。

每真实案例分别清空缓存并记录一次首调用，随后固定10对交替调用无缓存/已热缓存，顺序按重复序号交替，CUDA同步计时并记录显存。全部计时保留，不择优、不作冷磁盘吞吐承诺。两路径均含原JPEG字节读取；缓存路径省解码/resize/DINO提取。报告单次首调用、中位/范围和计时顺序限制，三种子不是独立视频样本。输入/权重/模型选择不变，核验报告/快照后独立推送并继续研究。
