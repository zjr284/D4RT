# 第41轮：COCO image标注的盲分组与查询适配

固定第37有效oracle标注及SHA、第40核验结果、OVIS类别表/元数据、四方案三种子权重/偏移；不网络重试、不读RGB模型、不训练/校准/评分。目录父路径作为候选视频分组，这是file_name派生分组，并非提供了官方video_id或track_id。

全部图像验证安全相对路径、唯一ID/路径、正整数尺寸、数字帧stem；按数字stem排序，组内唯一并维持尺寸。固定排除pilot 00000，不足8帧或尺寸不一致组明确记录，不按GT类别/面积或性能删候选。8帧用round(linspace(0,n−1,8))，首末都保留；未知道真实fps/时间戳，不能称每秒固定采样。

类别严格复用lowercase/underscore空格/合并空白名称映射，不合并更细类别。COCO RLE逐实例decode至原尺寸再nearest128；无掩码背景0，未知类别−1，任意两个实例重叠−1（同类也忽略），顺序无关。iscrowd区域忽略。GT仅作标签/评价坐标选择，不作为RGB特征或类别提示；输出始终26类，不因共同类限制预测候选。

按合格组排序均匀固定24组，首末两个已选帧共48张进行mask/query适配检查；不按已知类别像素是否存在补选。每帧只在GT>0位置用default_rng(20261041+image_id)抽256查询，不足256有放回；无已知前景返回空查询并记录。xy像素坐标、u=x/127/v=y/127、source time为八帧槽位；保存标签/坐标哈希、类别计数、全部排除与空帧。此为条件前景查询，不能估计自然背景准确率或OVIS AP。

正式确认与reserve尚不冻结：RGB/档案路径验证和OVIS重复筛查先完成。元数据路径交集只能发现同名，不能清除改名重复。后续独立固定筛查：外部所选8帧与所有可用OVIS原帧做原文件SHA和标准RGB像素SHA；完全相同则全视频排除；32x32灰度dHash64的Hamming<=6仅标记人工盲RGB复核，不按模型成绩剔除。记录缺失OVIS原帧，不能声称绝对无重复或预训练无重合。再冻结随机集合/排除清单与特征recipe，先冻结后评分。
