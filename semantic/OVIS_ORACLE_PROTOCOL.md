# 第四轮：冻结特征的真值监督诊断

## 目的与边界

区分伪标签错误、监督覆盖与当前冻结几何特征/线性分类头协议的限制。后续帧训练真值仅在本轮显式开放；本轮是 **oracle 诊断**，不能算作首帧弱监督方法的可部署成绩，也不是特征能力的数学上限。

## 固定三组

1. `pseudo`：复用第三轮原采样组的三个已验证模型。
2. `oracle_relabel`：保留第二轮全部已有训练查询的坐标、源时间和冻结特征，查训练真值替换标签；真值重叠区域 ID −1 的查询去除，不将其当背景。用于检验原查询上的标签错误。
3. `oracle_coverage`：同一 60 段训练视频，八帧均使用真值，从每帧前景/背景池各抽 128 查询；种子仍为 42+video_id。复用原 FP16 视频 memory，通过同一冻结查询嵌入和解码器计算特征。用于检验真值查询覆盖的整体干预。

两 oracle 组三种子 0/1/2、各 500 步；相同线性语义头，AdamW lr=0.001、weight_decay=0.01，每步前景/背景各 128、组内查询均匀抽样。每 50 步按验证宏 F1 选模型。测试不参与模型、参数或协议选择。

只处理 manifest 中的训练视频。验证/测试沿用原缓存和查询；训练/验证/测试视频无交集。开始前校验原缓存内容 SHA-256，记录 manifest、标注和模型配置指纹，不覆盖前三轮缓存或模型。产物目录为 `semantic_artifacts/oracle_probe/`。

## 指标与解释

报告三种子测试前景/总体宏 F1、背景 F1、前景正确率、前景被判背景率、逐类和逐帧指标；另报告选中模型在训练查询上的拟合表现与标签修正混淆矩阵。重标组改变标签组成员及抽样比例（仍每步前景/背景各半），不完全等同训练梯度中的单一标签替换；真值覆盖组改变训练查询分布和监督信息量，不单独归因于某个因素。

若标签修正恢复，则标签错误有可干预影响；若完整真值明显优于重标，则支持覆盖/代表性限制；若两者都低，尚不能唯一归因于冻结特征，还需比较训练预算、优化方式及非线性头。三个种子来自同一视频划分，不能视为跨划分泛化证据。
