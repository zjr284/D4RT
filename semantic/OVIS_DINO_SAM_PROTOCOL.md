# 第十五轮：固定DINOv2特征的SAM监督对照

问题：在已有更适合语义的DINOv2特征下，首帧GT＋SAM前景/背景是否比仅首帧GT提高新视频识别？分别在第十一轮random80/coverage80进行两个监督对照，两组均80段、同20段验证、共享新确认视频。

复用第十三/十四轮的六份源帧GT DINOv2头及验证偏移−1.5，不重新训练或重新校准。仅新训练两训练集的SAM监督头，各种子0/1/2、2000步；模型、特征预处理、分类头、优化器及前景/背景各128的组内均匀采样与前轮相同。每50步按原始验证宏F1选择权重；共享偏移按三种子平均验证宏F1、−8至+8步长0.25选择，同分绝对值更小再负值。确认分数不影响任何选择。

直接复用第十一轮已冻结SAM 2.1 tiny标签与实际查询：源帧GT实例提示传播到后7帧，正分/类间间隔>2、两像素侵蚀，所有提示实例logit<−2及两像素安全带才标背景，不确定像素忽略。后续训练帧GT只作既有教师诊断，不筛选或修改标签。不重新生成传播或改变阈值。每段训练的全部查询来自旧SAM缓存，DINOv2只读取对应RGB和查询坐标，不读取类别构造特征。

新提取后7帧SAM查询的DINOv2特征，首帧查询的特征值直接复用原源帧GT缓存，避免图像推理批量不同造成数值差异；先核对标签、坐标与目标/相机时间逐值相同，再复制相同查询特征。所有GT源帧样本与SAM组源帧子集完全一致。教师传播增加同视频时刻/像素，不增加独立训练视频。

新确认先排除已处理380段，从剩余227段以seed=20261017固定40段，保存清单后再计算输出。候选源帧类别信息已被检查，只称模型未评价视频，不按Bear、SAM失败或新类别挑视频。新查询从原GT固定采样，验证/确认不使用SAM。全部模型与背景偏移冻结后才生成确认logits。

保存两训练集内SAM−GT的三种子配对宏F1、前景宏F1、前景正确/背景/类间错误分解、源/后续帧、逐类/逐视频结果；保留负结果和训练缺失类别。固定seed=20261017的2000次视频bootstrap仅估计视频等权出现类宏F1差，不能当汇总类宏F1区间。四方案按平均验证宏F1选总体方案，不按确认选。

独立核验：重建新40段GT查询；核对100段训练的全部SAM标签/坐标等与原缓存及教师图一致；GT源帧特征逐值与旧缓存一致；复算12模型24份验证/确认输出、六份新头预算与校准，旧六头/偏移及教师输入哈希不变。DINOv2预训练OVIS图像重叠未知，验证集有此前选择影响；结论限于本特征/教师/预算协议，不代表全部SAM模型或官方OVIS AP。

入口：`.venv/bin/python -m semantic.dino_sam_control`，独立目录`semantic_artifacts/dino_sam_control/`。每轮核验后保存代码、报告、文本快照并独立提交、推送GitHub。不上传数据、权重、特征或第三方源码。
