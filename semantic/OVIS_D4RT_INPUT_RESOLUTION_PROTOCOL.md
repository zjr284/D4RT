# 第106轮：输入分辨率128/256的匹配控制

只在105独立核验并单独发布后执行。105隔离几何并规范源查询后SAM整体仍负，不能继续凭增加损失认定有效。检查本地权重model.yaml可见输入配置32帧、256×256；现有实验用8帧、128×128。本轮固定8帧，仅把原JPEG直接缩放尺寸从128改256；不声称恢复完整32帧训练配置，不把可能差异唯一归因全局细节（局部9像素RGB窗口和token网格也改变）。RGB仍0..1、BILINEAR；原复现训练数据代码亦0..1，不随意新增ImageNet归一化。

同原60train/20val、原128标签网格与原查询u=x/127/v=y/127/t_src；查询/标签/源帧GT及后帧SAM点、原三seed500步日程均不变，不重采样或把GT边界按256重标。source语义t_tgt=t_cam=t_src，仍读全8帧memory。四臂source_head/source_GT/source_SAM/source_extraGT；128四臂直接复用105的12终点与保存验证结果，不重训。256仅新12模型，同105每seed初始参数、头lr1e-3/LoRA1e-4/AdamW .01，GT64/额外GT32/SAM32前向，损失系数0/.25不变；头33306或头+rank8 alpha16 FF LoRA217626，语义tail FP32参数、base BF16/autocast、tail输入显式BF16。几何主路冻结独立且不添加几何保持损失。

冻结协议/代码/旧12状态/旧输出/旧特征/日程和图像指纹，先在固定最小训练ID13做B1全模型8×256编码及64query源prefix、tail的单次GT梯度可行性检查。该梯度不更新模型、不计训练步，不看验证分数；若OOM/非有限/显存已分配峰值超过7000MiB则记录失败并停止本轮，不能临时改精度/大小/帧数。通过后提全部80段新source prefix，逐值核对旧query/标签；memory token期望1025含aspect token，原128为257。新缓存保存实际FP32输出，训练/评价按明确BF16边界转换；主原权重不覆盖。随后固定训练12终点，全部权重先冻结才跑原验证，每步loss及时落盘，避免105轨迹丢失重现。

主对照是SAM相对GT的分辨率差中差：(SAM256−GT256)−(SAM128−GT128)，三seed与视频等权均保留。必要对照GT256−GT128、SAM256−SAM128、extraGT256−extraGT128、head256−head128和256下GT−head、SAM−extraGT。完整四臂×两尺寸×三seed汇总宏/前景宏、逐类/视频；没有搜尺寸、训练步数、损失权重、校准或早停。256外测资格仍须SAM对GT与extraGT全部三seed汇总宏差正且各视频等权均差正；资格仅允许另立新协议，不调用已用test20/外部40，不换默认。

12新模型×固定val首两段B1/B2×原/目标相机+1共72接口：几何逐值同256同批原base；B1语义逐值同新缓存分数；源语义变体逐值一致；B2与同批手工参照。128/256几何不要求互同，不把分辨率改变后的输出差说成三维真值改进。原105恢复和缺失trace诚实继承为复用对照限制。独立核验全部80RGB/query/特征、12初始化/预算/逐步loss/首梯度末优化器、12完整验证/72接口、复用12旧输出、全部差中差与指纹，报告后单独白名单提交推送。
