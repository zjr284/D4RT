# 第97轮：40组冻结结果的图像案例复核

本轮已查看全部6张案例拼图、35个查询点，并完成独立程序核验。只复查第93轮已有图像、标签和预测；没有训练、重新推理、改标签、改分数或更换部署模型。

## 本轮看到了什么

1. **人的错误识别有具体画面依据。** 选出的案例包含手、衣物、手与工具交界、远处的小人物，以及水印/字幕附近的查询点。整图能看出有人，不代表每个点都被正确分类。例如00631的前臂点两方案三个种子都预测背景，另一帧的手部点两方案又都正确。裁剪仅供查看，模型原来输入的是完整帧；这些现象不能证明模型只看局部，或确定错误的唯一原因。
2. **SAM既有计分上的纠正，也有恶化。** 00391的一处手指/黑色装置边界点，GT方案三个种子均为Person，SAM三个种子却给出其它类别。所有正负案例均保留。错误导向选点不代表总体发生比例，也不能拿这些代表案例重新证明总体收益。
3. **发现一个疑似标注语义问题。** 案例21（00381/00003.jpg，image ID 8680，原像素695,25）被原Person掩码覆盖，但查看完整原图，该位置看起来是电钻后方的包装/背景。图像ID、文件名、尺寸、原RLE命中均对应，并非程序关联错帧。它按原分数算SAM纠正成功，不能直接当作可靠的人体识别改进。这里只标出疑点，未由Codex观察替代GT，也未删除或重评分。
4. **鸟的改善仍然只来自一组视频。** 00821的8个采样帧中，所选点有3帧满足“GT三个种子全错、SAM三个全对”，1帧两者全错，4帧种子结果混合。原标注在这些点同时命中bird和未映射的magpie；严格规则过滤，原consensus规则保留。没有新的视频支持，也没有做物种鉴定，不能推广成SAM普遍提高鸟类识别。

## 对当前工作判断的影响

40组原测试和逐类整理已经完成；本轮把典型错误、种子差异与标注疑点落实到具体图像。模型是否稳定改进仍以原冻结测试为准：GT32没有确认优于GT256，SAM也未确认在这些视频上有稳定收益。严格评价只有Person；敏感性评价增加的Bird只有一组，其余共同类别支持不足。当前证据不能回答25类普遍泛化、自然像素误检或跟踪性能。

后续如要验证SAM或新损失函数，应另立模型改动和新数据协议；本轮没有启动这些新实验。当前截至10月27日授权的两项工作可按组会说明直接交付，无需重复测试这40组。
